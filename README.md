# Differentiable Hybrid Model for Debutanizer Distillation

End-to-end differentiable hybrid model combining a data-driven model (DDM) with
a first-principles model (FPM) for debutanizer column simulation. The DDM (MLP)
learns corrections to thermodynamic interaction parameters, feed quality, and
vapor pressure bias, while the FPM (Peng-Robinson EOS distillation solver)
provides physically consistent predictions.

Companion code for:

> **Hybrid Differentiable Programming for Distillation Column Modeling**
> Tae Hyun Kim, Joseph Sang-Il Kwon
> *Computers & Chemical Engineering*, 2026

## Architecture

```
Operating conditions ──► DDM (MLP 11→16→8) ──► delta_kij(6), q(1), delta_tvp(1)
                                                        │
                                                        ▼
                         FPM (JAX distillation solver + PR-EOS)
                                                        │
                                                        ▼
                         Predicted distillate composition + TVP
                                                        │
                                  Loss (MAPE vs plant data) ◄── Plant measurements
                                                        │
                              Backpropagation through entire pipeline
```

The gradient flows end-to-end: `ddm_params → MLP → kij → PR-EOS fugacity →
K-values → column solver → distillate composition → loss`. This is enabled by
implementing the entire thermodynamic pipeline in JAX with automatic
differentiation.

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Generate synthetic demonstration data
python -m scripts.make_synthetic_data

# Train the hybrid model (synthetic data, reduced epochs for demo)
python -m scripts.train_hybrid --epochs 50 --save-dir results/demo
```

## Key Design Decisions

**Split-JIT strategy**: The composition loss and TVP loss are JIT-compiled as
separate functions to avoid LLVM out-of-memory on the combined XLA graph. Gradients
are combined via VJP chain rule through the DDM MLP.

**Two-phase bubble-point solvers**: Wilson K Newton (robust init) followed by
PR-EOS Newton (kij gradient flows). `lax.stop_gradient` on Wilson phase since
Wilson K has no kij dependency.

**lax.scan column iterations**: A single compiled loop body instead of unrolled
copies, with `jax.checkpoint` for memory-efficient backpropagation.

**6-parameter kij correction**: Only C6+ (pseudo-component) interaction
parameters are corrected, as the pseudo-component introduces the largest
thermodynamic uncertainty.

## Reproducing Paper Results

The synthetic dataset provided is for code demonstration only. To reproduce
paper results, replace `data/debutanizer_synthetic_29days.csv` with your plant
data in the same column format and run:

```bash
# Full training (500 epochs, ~2-3 hours on GPU)
python -m scripts.train_hybrid --epochs 500 --save-dir results/full

# LOOCV (24 folds x 300 epochs each, computationally intensive)
python -m scripts.run_loocv --epochs 300

# Sensitivity analysis (3 configurations)
python -m scripts.robustness_sensitivity --epochs 200

# 29-day retrain (normal + turndown)
python -m scripts.retrain_29day --epochs 500
```
