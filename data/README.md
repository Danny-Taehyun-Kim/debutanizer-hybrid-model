# Data

## Synthetic Dataset

`debutanizer_synthetic_29days.csv` is a **synthetic** dataset generated by
`scripts/make_synthetic_data.py`. It contains 29 days of simulated debutanizer
operating data (24 normal + 5 turndown) with realistic ranges but **no real
plant measurements**.

To regenerate:
```bash
python -m scripts.make_synthetic_data
```

## CSV Columns

| Column | Unit | Description |
|--------|------|-------------|
| `Date` | — | Date string (YYYY-MM-DD) |
| `Balance_Status` | — | Always "Complete" for valid days |
| `Regime` | — | "normal" or "turndown" |
| `Feed_C2_mol%` ... `Feed_C6_mol%` | mol% | Feed composition (7 components) |
| `LPG_C2_mol%` ... `LPG_C6+_mol%` | mol% | Distillate (LPG) composition |
| `PIC3000_barg` | barg | Column top pressure (gauge) |
| `F_kmolh` | kmol/h | Feed flow rate |
| `D_kmolh` | kmol/h | Distillate flow rate |
| `RD_ratio` | — | Reflux ratio (L/D) |
| `LPG_TVP_kgcm2` | kgf/cm² | True Vapor Pressure of LPG product |

## Components

| Index | Label | Species |
|-------|-------|---------|
| 0 | C2 | Ethane |
| 1 | C3 | Propane |
| 2 | iC4 | Isobutane |
| 3 | nC4 | n-Butane |
| 4 | iC5 | Isopentane |
| 5 | nC5 | n-Pentane |
| 6 | C6+ | n-Hexane (pseudo-component) |

## Using Your Own Data

Replace `data/debutanizer_synthetic_29days.csv` with your plant data in the same
column format, or pass `--csv <path>` to any script.

## Notes on the synthetic generation

The synthetic distillate compositions are produced by running the JAX FPM with a
"true" kij that includes condition-dependent C6+ perturbations, followed by
realistic measurement noise. The resulting compositions are internally consistent
with the FPM physics but do not reproduce the sharper C3–nC4 split observed in
the real plant, because the proprietary C6+ composition of the actual feed differs
from the n-hexane surrogate used here in a way that this synthetic generator does
not attempt to replicate. The dataset is intended to preserve the workflow
behavior — a baseline-vs-plant nC4 mean absolute error of approximately 4–7 mol%
that the hybrid model can correct — rather than to reproduce the absolute
distillate composition of the real Ghana National Gas plant.
